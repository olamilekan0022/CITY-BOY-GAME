CITY BOY 🥷 — PLAYABLE WEB DEMO

Created as an original, fictional urban life exploration game prototype.

HOW TO RUN
1. Keep index.html, css/ and js/ together.
2. Open index.html in a modern browser with an internet connection.
3. Babylon.js loads from its public CDN.

CONTROLS
- WASD or arrow keys on keyboard.
- On-screen directional buttons on touch screens.
- CITY SHIFT awards 50 fictional City Cash.
- Style Shop sells cosmetic outfits using virtual currency.

NOTES
- This is a single-player prototype.
- City Cash is fictional and has no cash value.
- No real-money purchases, weapons, or criminal activity.
- Progress is saved locally in the browser on the same device.
- Online multiplayer, accounts, cloud saves, and chat are not included.
